# Looptik

**Loop + Optic + Pic. 짧은 영상 루프 배경화면 제작에 최적화된 광학 모션 스튜디오입니다.**

Canvas 인터레이싱 + CSS 슬릿 오버레이를 사용하는 독립형 웹 앱입니다. 제공하신 원본 HTML의 절차적 모션 생성기를 활용했습니다.

## 실행

저장소를 다운로드한 뒤 index.html을 최신 브라우저에서 열거나 정적 웹 호스팅에 올리세요. 외부 라이브러리, 설치, 빌드가 필요 없습니다. 모바일 기울기 센서는 지원되는 기기와 HTTPS 환경이 필요합니다.

## 기능

- 말·큐브·별·보행 프리셋 4종
- 마우스·터치 드래그, 좌우 방향키, 자동 재생과 속도 조절
- 합성·비교·베이스 뷰, 슬릿 표시 전환과 위치 초기화
- 프리셋과 동영상의 6–8프레임 조절, 슬릿 폭 1–5px
- 동영상 1개에서 첫 최대 2초를 균등 추출
- 연속 사진 3–8장: 파일명 숫자 순서 정렬
- 브라우저 내 파일 처리, 서버 전송 없음

## 출력

- 1080×1920 약 10초 숏폼: 베이스 노출 0–2초 → 슬릿 진입 2–3초 → 모션 3–8초 → 슬릿 들어보기 8–10초
- 1080×1920 약 6초 배경화면용 루프, 3주기. 문구 없이 화면을 채우는 중앙 크롭.
- 720×720 합성 베이스 PNG
- A4 PDF 2페이지: 180×180mm 무손실 RGB 베이스와 벡터 슬릿. 두 페이지 모두 100% 크기로 인쇄하고 슬릿은 OHP 필름에 출력합니다.

영상은 MediaRecorder가 MP4를 지원하면 MP4/H.264로, 미지원 시 WebM으로 저장합니다. 무음이며 실제 길이와 프레임률은 브라우저 성능에 따라 조금 달라집니다. 렌더링 중 탭을 숨기면 작업을 취소합니다. WebM→MP4 변환은 별도 도구를 사용하세요.

## 제한

- Live Photo 변환, Android 자이로·런처 연동 라이브 배경화면 앱, OS 배경화면 자동 적용은 포함하지 않습니다. 플랫폼별 별도 앱/변환이 필요하고 잠금화면 동작은 OS마다 다릅니다.
- 자동 배경 제거와 서버 FFmpeg 변환은 포함하지 않습니다. 대비가 높고 배경이 단순한 소스를 사용하세요.
- MP4/MOV도 브라우저가 코덱을 지원해야 합니다. 사진은 장당 25MB, 영상은 150MB까지 받습니다.
- 실제 모바일 센서 하드웨어 검증은 하지 않았습니다. 센서 미지원·권한 거부·데이터 부재를 안내합니다.

## 검증

Chromium에서 런타임 오류 없음, 390px 모바일 가로 넘침 없음, 이미지 정렬 및 픽셀 인터레이싱, 드래그·키보드·프레임 전환·비교 뷰, 영상 6→8프레임 재추출, MP4 생성 및 취소를 확인했습니다. ffprobe로 H.264 / 1080×1920 / 약 10초 및 약 6초를 확인했고, PDF A4 2페이지 구조도 검사했습니다.

## 모바일 버전과 컬러 설정

동일한 index.html에서 화면 폭 760px 이하일 때 모바일 인터페이스로 전환합니다. 별도 설치는 필요 없습니다.

- 하단 미리보기 / 소스 / 설정 탭과 항상 보이는 루프 저장 버튼
- 9:16 배경화면 중앙 크롭 미리보기와 1:1 원본 전환
- 가로 터치는 슬릿 조작, 세로 터치는 스크롤
- 손가락으로 누르기 쉬운 버튼과 범위 조절기, 하단 내보내기 시트
- 화면 안전 영역과 가로 모드 대응
- 설정 → 모션 컬러: 세이지·민트·스카이·코랄·라벤더·골드 6종
- 모션색과 배경색 직접 선택, PNG·PDF·영상 출력에 동일 적용
- 업로드 소스는 기본 원본 색상 유지. '업로드 영상·사진에도 색상 적용'을 켜면 명도에 따라 선택한 두 색으로 변환. 다시 끄면 원본 복원

모바일 화면(320–700px), 터치 제스처, 가로 모드, 데스크톱 복귀, 컬러 합성 픽셀과 MP4/PNG 출력을 Chromium 에뮬레이션에서 검증했습니다. 실제 iOS/Android 기기와 센서의 하드웨어 검증은 수행하지 않았습니다.
